# Portal OVA

Portal de Electiva Profesional I de Ingeniería de Sistemas. Incluye proyectos por semestre, evaluaciones y juegos.

**[Abrir Portal OVA](https://lissette-842.github.io/portal-ova/)**

GitHub Pages publica el sitio desde la raíz de `main`. Supabase ya autoriza `https://lissette-842.github.io/portal-ova/index.html` para los enlaces de confirmación de cuentas.

Para ejecutar una copia local con Python, abre una terminal en la raíz de este repositorio y ejecuta:

```powershell
python -m http.server 8001 --bind 127.0.0.1
```

Abre [http://127.0.0.1:8001/](http://127.0.0.1:8001/). El portal requiere Internet para consultar Supabase.

## Glosario y debates

El [glosario por empresa](https://lissette-842.github.io/portal-ova/?seccion=glosario) reúne 55 conceptos iniciales de nueve empresas. Selecciona una empresa para buscar o agregar un término. En **Ver debates** puedes abrir una conversación y responder con un nombre o alias público. Los aportes se comparten mediante Supabase.
